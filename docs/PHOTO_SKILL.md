# 上传照片，制作指定人物的桌宠

小薛同学桌宠提供一个可单独分发的 Codex skill。上传照片、说明要制作照片中的哪位人物，就能让支持图像生成的 Codex 按既定流程制作统一人物、连续动作和可运行桌宠。

## 怎么用

把 `xiaoxue-pet-skill.zip` 解压后，将其中的 `xiaoxue-pet` 文件夹放入 `~/.codex/skills/`，新开一个 Codex 会话。

上传清晰人物照片，输入：

```text
使用 $xiaoxue-pet，把上传照片中戴眼镜的女生做成动漫桌宠。
保持脸型、发型、服装一致，采用精细柔和的 Q 版风格。
需要走路、眨眼、挥手、喝水和三种比心，给我动作预览及 Windows 安装包。
```

示例中的人物描述应换成你的目标人物。一张清晰图可以开始；多张正面、侧面和全身图更有助于保留特征。没有其他人物时，不必重复说明位置。

只想先看效果，可以说“先只做形象预览”。需要换衣服或改画风时，在开始时说明即可。

## 会得到什么

- 同一个角色的透明全身基准图、视图和动作素材。
- 可播放的动作预览 HTML、动作总览 PNG；能检查抬手和收手。
- 独立源码项目：不同人物使用不同应用标识和设置目录。
- 在 Windows 构建环境完成后，提供安装 EXE、免安装 ZIP 和验证记录。

默认动作包括走路、眨眼、挥手、喝水、三种比心，以及看书、坐着、睡觉、蛋糕、害羞、开心、伸懒腰等姿势。技能会按实际素材质量调整，静态陪伴姿势不会被声称为全部有连续原画动画。

## 为什么附带模板

skill 不依赖作者电脑上的项目路径，也不用先下载一个人物桌宠再覆盖图片。随包附带经过测试的代码模板、构建脚本和许可证；不附带真人照片、原人物图集或私人配置。制作脚本检查透明背景、帧完整性和尺寸，并从新人物生成图标。

脸型一致、衣服细节和手部自然度仍需要逐张查看；自动补帧不能保证每个人物都自然，必要时会重画关键姿势。不会使用分层肢体拼接。

## 环境与轻量要求

需要支持图像生成的 Codex 环境、Python，以及构建时可安装的依赖。Windows EXE 要在 Windows 上构建；缺少条件时会明确说明剩余部分。skill 是制作流程和模板，不是桌宠设置页里的照片上传功能，也不是随时在后台运行的 AI 模型。

运行包仍使用 119/187/238 像素三档、相邻两帧按需读取、2 MiB 混合缓存和自动避让。生成原画、补帧和模型计算发生在制作阶段，不增加已安装桌宠的常驻模型内存。完整进程内存随系统、Qt 和运行状态变化，不能用缓存值代替。

桌宠中的 DeepSeek Key 用于可选文字聊天，不能代替图像生成工具。默认只生成本地文件；输入照片、Key 和私人配置不进入公开包，也不会自动上传 GitHub。
