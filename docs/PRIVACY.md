# 数据与联网说明

普通动作、提醒、专注、设置和避让在本机执行。没有 QQ 监听、联系人读取、遥测上报和后台生成图片任务。

| 数据 | 保存或发送位置 |
|---|---|
| 大小、模式、位置、城市、DeepSeek Key | config.json |
| 昵称、提醒、专注统计、偏好 | companion-state.json |
| AI 输入和必要的近期上下文 | 用户发送时传给 DeepSeek |
| 查询城市 | 用户点击天气时传给 wttr.in |
| 前台程序/窗口状态 | 本地判断避让，不上传 |

安装版与免安装版配置位于 `%LOCALAPPDATA%\XiaoxuePet\`；源码版在项目目录。
Key 当前明文保存，勿提交或分享。仓库只提供空 Key 的 config.example.json。
卸载默认保留设置，用户可自行删除配置目录以清除本地内容。
发布包采用文件白名单，排除配置、照片、日志、联系人信息、历史备份和开发环境。
