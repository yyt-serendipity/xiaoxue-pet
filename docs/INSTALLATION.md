# 安装与旧版迁移

最新版安装器支持自定义本地目录，例如 `D:\Apps\XiaoxuePet`。安装版不需要 Python 或旧版虚拟环境。

1. 先从旧程序的托盘菜单选择退出。
2. 安装当前 Release 的 Setup.exe，或完整解压免安装包。
3. 若旧版由 Python 源码启动，确认它的开机启动快捷方式已停用或改为新 EXE，避免重复运行。
4. 新版启动成功后，旧程序专用目录和专用虚拟环境可按需手动删除；勿删除共用 Python、项目资料或个人照片。

安装版设置保存在 `%LOCALAPPDATA%\XiaoxuePet`，不在安装目录。源码版设置保存在源码目录；需要迁移时，先备份设置，并在新旧程序都退出后复制 `config.json` 与 `companion-state.json` 到安装版设置目录，不覆盖已有的新设置。配置可能包含私人 Key，不要上传仓库。

升级保留动作速度偏好。想使用当前舒缓节奏，请在「小屋 → 设置 → 动作节奏」选择 0.75×。
