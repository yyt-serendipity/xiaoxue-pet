# 运行约束

默认三档：119、187、238 像素。306 是构建中间尺寸，非运行设置。
动画源图通过 FramePair 最多保留两帧；非当前动作释放；混合缓存 2 MiB；静态图只驻留当前大小。
`body_motion.py` 仅对完整人物做轻微旋转、缩放和起伏，起停用时间相关包络平滑，不拆分肢体。`MotionPosition` 累计小数坐标并在绘制时补偿亚像素偏移；拖拽或停靠后的外部移动会重新对齐，不能再次逐帧截断浮点位移。
活跃约 20ms，可见待机 33ms，睡觉 100ms，隐藏 1000ms。提高可见待机频率有绘制成本，不能宣传为零开销；隐藏和睡觉使用低频定时，不启用全局高频轮询。
隐藏后停止绘制，约 5 秒释放素材，恢复再加载；不能在隐藏状态继续补帧。

看书统一开始 30 分钟专注，重复点击保留截止时间。提醒在专注、睡觉、安静模式、隐藏/避让时暂缓，避免恢复时堆叠。
陪伴页默认三列四行动作，底部无状态/计时文字。快菜单保持简洁，不把所有功能塞进新窗口。

自动避让结合 Windows 通知状态、前台窗口客户区和应用名单；普通最大化不是全屏。前台名单不能改成扫描所有后台进程并一律隐藏。保留恢复延迟与手动隐藏。

测试通常运行 `python -m unittest discover -p "test_*.py" -q`；无界面测试可设置 QT_QPA_PLATFORM=offscreen，启动用户桌宠前必须清除该环境变量。
测性能注明尺寸、动作、状态、工作集/私有内存与测量时长，不能拿缓存值冒充进程总内存。

默认动作速度 0.75×（舒缓），保留 1×、1.5×、2×。肢体完整帧和整体运动统一速度，行走步态按距离推进，不重复减速；呼吸相位累计时间。不要通过降低刷新频率实现慢动作，不要把专注 / 提醒计时或眨眼一并拉慢。
