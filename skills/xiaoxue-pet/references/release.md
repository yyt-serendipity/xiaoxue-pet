# 发布检查

使用项目自己的 `scripts/build_release.py`。维护本产品时保留小薛同学名称；制作其他人物时使用用户选择的名称和新人物图标，不保留原角色图标。主项目使用白名单导出工具；独立模板项目按照片流程白名单整理源码。
保留许可证与上游致谢，不能将独立品牌表述成基础代码完全原创。

禁止将 config.json、companion-state.json、API Key、真人照片、聊天记录、联系人、旧备份、虚拟环境或大尺寸制作缓存放进公开包。
安装运行包只包含小/中/大、缩略图和必要运行依赖。源图可放源码包；运行时不读取源图。

安装器支持可编辑路径和目录选择，升级默认沿用已登记目录，配置继续保存在独立用户数据目录。构建器从当前角色的 `prepared/238/正面.png` 嵌入安装页人物预览；新人物不能沿用示例头像。`--capture` 使用演示路径捕获真实安装控件，不执行安装，也不暴露本机用户名。

实际验证：源码测试、完整素材重建（若素材有变）、冻结 EXE 离线 smoke test、安装包测试解压、卸载仅删除清单文件、未知文件保留、SHA-256。
界面截图使用真实控件/窗口捕获，区分截图、原画与帧表。不要截图个人桌面或密钥输入内容。

未签名的 EXE 应明确标注，不让用户关闭安全防护。外部发布是独立动作：本地制作成功不自动授权新建仓库、推送或发布 Release。
